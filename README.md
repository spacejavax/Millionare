## How to run the project
1. Clone the repository to your device
```sh
git clone https://github.com/spacejavax/Millionare.git
```
2. Install the project's dependencies
```sh
py -m pip install pygame-ce
```

3. Run the game:
```sh
python main.py
```
On Windows powershell try 
```sh
py main.py
```
(This is run on pybag)

## Information about the Millionaire game//How to play??
You start with 1000$ in cash. With those cash you can buy shares in different companies. But! The values goes down and up randomly. You have to evaulate each companies risk rate, and buy and sell at the right moment. The game ends at day 10, so make sure not to go broke before that:p After 10 days, you'll see if you became rich rich. And now that you're rich you can buy from the shop! ## Proccess
I started building a pygame window with titles and the amount of cash you could spend. Then companies, prices, buy and sell buttons were added. First as a test, then I changed the whole code so the layout and design looked nicer (more kawai). I stored each company’s name, price, risk level, owned shares, and price history in a dictionary. A loop was created for each copmany. Mouse-collision detect which buy or sell button you click. If you buy, your current price is substracted from your cash. if you sell its added back. I also created a ten day-limit, hovering effects and graphs. I will continue working on a shop as well, selling nice things you can buy with the money.



## Challenges
Hardest part for this stock market game was creating the graph. I did not know python used reversed coordinates. It was hard figuring out how to solve it in code. Another challange I faced was making sure the buttons for sell and buy was correctly placed. Sometimes they overlapped, sometimes they were too far from each other.
